# Reglas Críticas del Proyecto

## Regla Principal y Absoluta: NO NAVEGAR
- **PROHIBIDO EL USO DEL NAVEGADOR**: El agente tiene estrictamente prohibido usar herramientas de navegación (`browser_subagent`, interacción con el navegador, apertura de páginas, screenshots del navegador o cualquier herramienta de browser).
- El agente **NUNCA** debe abrir ventanas de navegador ni navegar en URLs.
- Todo el trabajo debe realizarse exclusivamente a nivel de edición de código (HTML, CSS, JS), archivos locales y comunicación directa con el usuario.
